## 关于我

我目前把主要精力放在空中具身智能无人机项目上，关注从传感器输入、定位到规划器输出的真机链路是否可靠。

- 公开代码以 `C++` 为主，也使用 `C`、`Python`、`CMake` 与 `Shell`
- 公开仓库把复杂系统拆成可以观察、验证和复现的小步骤
- 项目文档包含日志、测试清单、安全边界和团队协作记录

## 代表项目

### [SUPER_DRONE_TEAM](https://github.com/Zzzsy01/SUPER_DRONE_TEAM)

面向空中具身智能无人机的队友协作仓库，基于 `HKU-MARS/SUPER` 整理，当前聚焦真机链路测试准备。

- 计划验证 Jetson Orin NX、Livox Mid-360S、定位 / odom 与 SUPER planner 的连接情况
- 提供中文协作入口、真机测试清单、安全规则和日志反馈模板
- 仓库主要语言包括 C++、C、Python 与 CMake

[查看项目 →](https://github.com/Zzzsy01/SUPER_DRONE_TEAM) · [中文协作入口 →](https://github.com/Zzzsy01/SUPER_DRONE_TEAM/blob/main/README_TEAM_CN.md)
